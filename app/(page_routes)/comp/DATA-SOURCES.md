# Comp company data sources

The standalone company catalog combines the existing Comp dataset, its nearshore research, company profiles from [Remote In Tech](https://github.com/remoteintech/remote-jobs), and public employer job-board feeds.

Remote In Tech snapshot: `fa2253f1ed02cc4d8f59ab3ccc831b008cdd7189`. Profile metadata is attributed on each imported company card. Technology and region labels from a historical directory profile do not imply a current vacancy or current country eligibility. Employer-board metadata is retained separately with the date checked.
